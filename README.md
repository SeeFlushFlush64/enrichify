# Enrichify

Enrichify is a web-based email enrichment application built using ASP.NET MVC. The application integrates with third-party APIs to enrich contact data and store validated results in a SQL Server database.

This project was developed with a focus on reliability, data validation, and API error handling.

---

## Features

- Email enrichment via third-party API integration
- RESTful API communication with error handling and rate limiting
- Data persistence using SQL Server
- Responsive web interface
- Secure handling of API credentials

---

## Tech Stack

- ASP.NET MVC
- C#
- SQL Server (MSSQL)
- RESTful Web APIs
- HTML, CSS, Bootstrap, jQuery
- Git / GitHub

---

## Quality Assurance & Testing

Quality assurance was considered throughout development. Manual testing and validation covered:

- Functional testing of core enrichment workflows
- API response validation and error handling scenarios
- Regression testing after feature changes
- Basic UI and responsiveness checks

Detailed QA documentation is available in `QA-NOTES.md`.
